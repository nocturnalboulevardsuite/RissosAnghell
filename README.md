## 📜 Descripción
Bienvenido al archivo maldito. Este repositorio contiene el código fuente de **El Rincón del Rissos**, un blog web estilo "Horror Core" con estética de VHS antiguo, cintas perdidas, y toques cibernéticos oscuros. Las historias perdidas han sido recuperadas.

## 💀 Tecnologías Utilizadas
- **Python 3.x**
- **Streamlit** (Para el renderizado de la interfaz web)
- **HTML/CSS** (Inyectado para animaciones de arañas, efectos VHS y aberraciones cromáticas)

## 📼 Instalación y Ejecución

1. Clona este repositorio o descarga los archivos.
2. Abre una terminal en la carpeta del proyecto.
3. Instala Streamlit si no lo tienes:
   ```bash
   pip install streamlit
   ```
4. Ejecuta la aplicación de la cinta maldita:
   ```bash
   streamlit run app.py
   ```

## 🕷️ Características
- Animaciones espeluznantes (arañas caminando por la pantalla).
- Páginas dinámicas simulando diferentes cintas VHS.
- Cambios de paleta de colores y estética dependiendo de la historia.
- Diseño Web adaptado a temáticas Góticas, Cyber-Horror, Tron Ares y Matrix.
